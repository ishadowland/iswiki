## 风格

- 每个 `.md` 是 1 个独立主题
- 开头用 `# Topic — 短描述`,然后是 `> 学习笔记 · 调研时间`
- meta 行用 `> 仓库: <url> · License: <X> · ...`
- 自由 sections,中文为主
- commit 风格: `docs: add <X> research notes` 或 `docs: update <X>`
